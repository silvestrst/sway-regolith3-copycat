# sway-regolith3-copycat
Regolith3 desktop environment approximation on ubuntu 26.04 with standard ubuntu repository packages.

Built because Regolith had no packages for Ubuntu 26.04 when the author did a fresh install of it
(August 2026), so the desktop was recreated from what the standard archive already ships.

Install script and configuration files: [desktop/](desktop/README.md)

**Disclaimer:** the install script and this repository were put together after the fact, from
a machine that had already been set up. The script has not yet been run on a fresh
Ubuntu 26.04 installation, so it is untested end to end: it may fail, and the result may not
look or behave exactly like the original setup.
